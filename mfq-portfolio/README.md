# Dr. Muhammad Farrukh Qureshi - Academic Portfolio

A modern, responsive academic and research portfolio website built with React and Vite.

## Features

- **Modern Design**: Dark navy/charcoal theme with cyan/teal accents
- **Responsive**: Beautiful on desktop and mobile
- **SEO Optimized**: Meta tags, OpenGraph, structured data
- **Accessible**: Semantic HTML, proper ARIA attributes
- **Fast Loading**: Optimized builds with minimal dependencies
- **Data-Driven**: Easy to update publications, projects, and research info

## Sections

1. **Hero**: Introduction with research pipeline visualization
2. **Statistics**: Key metrics (publications, citations, h-index)
3. **Research Areas**: Interactive cards showcasing research focus
4. **Publications**: Searchable, filterable publication browser
5. **Academic Journey**: Timeline of education and positions
6. **Awards & Grants**: Recognition and funding
7. **Contact**: Collaboration inquiry form

## Tech Stack

- React 19
- Vite (build tool)
- Lucide React (icons)
- CSS Variables (theming)
- Intersection Observer (animations)

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Customization

### Update Personal Information

Edit `src/data/portfolioData.js` to update:
- Personal details
- Research areas
- Publications
- Projects
- Awards
- Teaching courses

### Styling

Modify `src/index.css` to customize:
- Colors (CSS variables)
- Typography
- Spacing
- Animations

## Deployment

The site can be deployed to any static hosting:
- GitHub Pages
- Netlify
- Vercel
- AWS S3 + CloudFront
